## Дизайн-система (не змінювати без прямого запиту)

```css
--bg: oklch(96.5% 0.012 145)
--bg-alt: oklch(93.5% 0.016 145)
--ink: oklch(24% 0.045 155)      /* колір тексту/заголовків — навмисно майже чорний, НЕ те саме що --accent */
--ink-soft: oklch(38% 0.03 150)
--line: oklch(85% 0.02 150)
--accent: #1A5E33                 /* брендовий зелений — кнопки, іконки, лого */
--dark: oklch(17% 0.025 155)
--paper: oklch(98% 0.006 100)
```
Заголовки — Playfair Display (500–700), текст — Outfit (300–600). Inter заборонено.
Іконки — тонкі лінійні (stroke ~1.4–1.6px), без кольорових підложок. Без нумерації розділів 01/02/03.
Позиціонування B2B: без "з душею", без емодзі-будиночків, без кітчу (мітли, бульбашки) — і принципово без стокових фото (рукавички/розпилювачі), які роблять сайти конкурентів "дешевими".

**Адаптивність:** перевірено реальним виміром (`scrollWidth` vs `innerWidth`, не на око) — без горизонтального overflow на 320px, 375px, 768px, 1024×600 (нетбук), 1920px. Breakpoints: 880px, 560px, 380px.
